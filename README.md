# GEN-AI with SQL (Text-to-SQL Application)

## Overview
This project is a Generative AI-powered application that allows users to interact with databases using natural language.  
Instead of writing SQL queries manually, users can simply ask questions, and the system generates and executes SQL queries to return results.

## Problem Statement
Querying databases requires knowledge of SQL, which can be a barrier for non-technical users.  
This project solves that by enabling users to retrieve data using natural language, making data access more intuitive and efficient.

---

## Architecture

User Query (Natural Language)  
→ LLM (SQL Generation)  
→ SQL Query Execution  
→ Database  
→ Results (Table / Output)

---

## Tech Stack

- Python  
- Streamlit (UI)  
- Large Language Models (LLMs)  
- SQL (Database Interaction)  
- Prompt Engineering  


---

##  Features

- Natural language to SQL conversion  
- Automatic SQL query generation  
- Query execution and result display  
- Interactive web interface using Streamlit  
- Simplified data access for non-technical users  

---

## Example Queries

- "Show all records from the dataset"  
- "Find the average value of column X"  
- "List top 5 entries based on sales"  
- "Filter data where condition Y is true"
